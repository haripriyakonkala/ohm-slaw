# Ohm's Law Simulation

## 📌 Project Description

This project demonstrates Ohm's Law using Python.
It calculates voltage, current, and resistance and
simulates the relationship between resistance and current.

## ⚡ Formula

I = V / R

V = I × R

R = V / I

## 🛠️ Technologies Used

- Python
- Matplotlib
- GitHub

## 📊 Simulation

The simulation plots the relationship between
resistance and current for a constant voltage.

## 🎯 Example

Voltage = 12 V
Resistance = 6 Ω

Current = 12 / 6 = 2 A
